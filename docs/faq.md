## 互換性

??? question "Altair-X 以外のキーボードにも使えますか？"

    PCB は Altair-X 専用です。

??? question "オリジナルの Altair-X から不可逆な改造が必要ですか？"

    基本的に必要ありませんが、ガスケットは純正の右手側 PCB から再利用する前提です。

??? question "ZMK / 無線化はできますか？"

    本 Mod は QMK + RP2040 の USB-C 有線構成のみで、無線には対応していません。

??? question "キーマップを変更できますか？"

    VIA に対応しています（[キーマップの変更](manual/keymap.md)）。

## 使い勝手

??? question "打鍵中に誤ってカーソルが動きませんか？"

    数ヶ月使っていますが、特に問題なさそうです。

??? question "普通のマウスの代わりになりますか？"

    ゲームなどには向きません。

??? question "ThinkPad の TrackPoint キャップが使えますか？"

    2.4mm 角の軸に装着できるロープロファイルタイプのものであれば使用可能と思われます。クラシックキャップを使用したい場合、軸のサイズを変換する必要があります。

## メンテナンス

??? question "キャップが汚れた / 滑るようになった"

    キャップを交換することをおすすめします。

??? question "分解して再組み立てできますか？"

    可能です。
