# トラブルシュート

症状から該当する項目を探してください。原因が特定できない場合は [Issues](https://github.com/kazubu/axtp-guide/issues) に症状と写真を添えて報告してください。

## キーボード全般

??? failure "PC に認識されない"

    - [ ] 別の USB-C ケーブル / ポートで試す（充電専用ケーブルではないか）
    - [ ] BOOTSEL を押しながら接続し、`RPI-RP2` ドライブとしてマウントされるか確認する
      （マウントされるならハード的には生きているので、ファームウェアを再書き込みする）
    - [ ] RP2040 周辺・USB コネクタのはんだ不良や短絡を確認する
    - [ ] FPC ケーブルを一旦外して認識するか確認する（電源の短絡切り分け）

??? failure "特定のキーが反応しない"

    - [ ] スイッチの足が曲がっていないか確認する
    - [ ] ホットスワップソケットのはんだをやり直す
    - [ ] 行 / 列の単位で反応しない場合は基板側を疑う

??? failure "1 回の打鍵で複数入力される（チャタリング）"

    - [ ] スイッチを交換して切り分ける
    - [ ] はんだ不良がないか確認する
    - [ ] デバウンス時間を延ばす（`config.h` の `DEBOUNCE`）

## トラックポイント

??? failure "カーソルが全く動かない"

    - [ ] FPC ケーブルが基板側・マウント基板側の両方で奥まで挿さり、コネクタのラッチが閉じているか確認する
    - [ ] FPC ケーブルの端子面の向きを確認する（どちらの端子も基板側を向く）
    - [ ] FPC ケーブルの折り曲げ部で導体が切れていないか確認する
    - [ ] SK8707-01-004 の制御基板・スティック基板のはんだ不良・ブリッジを確認する
    - [ ] VCC / GND 間が短絡していないかテスターで確認する

??? failure "何もしていないのにカーソルが勝手に動く（ドリフト）"

    - [ ] 通電時にスティックに触れていないか確認する（起動時にキャリブレーションされます）
    - [ ] 一度 USB を抜き、スティックに触れずに再接続する
    - [ ] スティックがカバーやキーキャップに常時押されていないか確認する（干渉）
    - [ ] FPC ケーブルがマウント基板を引っ張っていないか確認する
    - [ ] マウント基板の固定ネジを締めすぎていないか確認する

??? failure "動く方向がおかしい / 上下左右が逆"

    - [ ] モジュールの取り付け向きを確認する
    - [ ] スクロール方向だけが逆の場合は `CUSTOM(11)`（スクロール方向の入替）を試す

??? failure "動きがカクつく / 飛ぶ"

    - [ ] FPC ケーブルの接触不良を疑い、一度抜き差しする
    - [ ] ポインタ速度を下げてみる（`CUSTOM(3)`、[キーマップの変更](manual/keymap.md)）

??? failure "スクロールできない"

    - [ ] スクロールモードに入っているか確認する（`CUSTOM(8)` / `CUSTOM(9)`、[キーマップの変更](manual/keymap.md)）
    - [ ] スクロールバッファサイズの設定を確認する（`CUSTOM(5)`）

??? failure "クリックが効かない"

    - [ ] キーマップでマウスボタンが割り当てられているか確認する
    - [ ] Auto Mouse Layer が有効なレイヤー側にマウスボタンを置いているか確認する
    - [ ] 物理スイッチを使っている場合はスイッチと配線を確認する

??? failure "Auto Mouse Layer が動かない / 勝手に切り替わる"

    - [ ] `AML_THRESHOLD` が大きすぎて有効化されていないか確認する
    - [ ] 逆に、わずかな動きで切り替わる場合はしきい値を上げる
    - [ ] 保持時間（`AML_TIMEOUT_MS`）が短すぎないか確認する
    - [ ] 定数の変更には再ビルドが必要です（[キーマップの変更](manual/keymap.md)）

## 最終手段

- [ ] EEPROM をクリアして設定を初期化する（`CUSTOM(1)` または `QK_CLEAR_EEPROM`）
- [ ] ファームウェアを再書き込みする（BOOTSEL を押しながら接続 → `RPI-RP2` に `.uf2` をコピー）
- [ ] FPC ケーブルを外し、キーボード単体で動作するか確認して切り分ける
